🎙️✨ Smart Arabic Caption ✨🎙️
🚀 A professional, game-changing tool for generating automated Arabic translations and captions for videos! This project is specifically designed to conquer Right-To-Left (RTL) formatting issues and ensure precise word-level synchronization. Making Arabic video content production faster, smoother, and more professional than ever! 🎬🔥

🌟 Key Features 🌟
✅ Full RTL Support: Correctly processes Arabic text from right to left without disconnected or distorted letters. No more backward text! 🧩

🤖 AI-Powered Auto-Generation: Converts speech to text with blazing accuracy, taking various vocal dialects into account. 🗣️🎙️

⏱️ Perfect Sync: Accurately links spoken words to the exact time frame in the video. ⏳🎯

🎨 Custom Styling: Modify font types, sizes, colors, and backgrounds to perfectly match your video's unique brand identity! 🖌️✨

📁 Flexible Export: Supports exporting .srt files or hardcoding captions directly onto your video masterpiece. 🎞️📥

⚙️ Prerequisites ⚙️
Ensure the following software is installed on your machine before starting the magic:

🐍 Python 3.8+

🎞️ FFmpeg (for smooth video and audio processing)

💻 Installation 💻
Clone the repository: 🚀

Bash
git clone https://github.com/AnasSlah/Smart-Arabic-Caption.git
cd Smart-Arabic-Caption
Install dependencies: 📦

Bash
pip install -r requirements.txt
🎮 Usage 🎮
Place your video in the same project directory, then fire up the tool via the terminal using this simple command:

Bash
python main.py --input your_video.mp4 --output final_video.mp4
(💡 Pro Tip: You can easily tweak variables within the code to change font types or colors exactly as you desire!)
